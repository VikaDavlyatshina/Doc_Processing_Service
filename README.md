# Doc_Processing_Service

Сервис для обработки загружаемых документов. API для загрузки, проверки и модерации документов с асинхронными уведомлениями.  
Роли: пользователь (создаёт документы), модератор документов (подтверждает/отклоняет), модератор пользователей 
(может восстановить удаленный аккаунт) администратор.

## Описание

Сервис позволяет зарегистрированным пользователям загружать документы (PDF, JPEG, PNG, DOC, DOCX).  
Модератор проверяет документы через Django admin или API, меняет статус, оставляет комментарий при отклонении.  
Все уведомления отправляются асинхронно через Celery + Redis.

## Возможности

- Регистрация и авторизация пользователей (JWT)
- Загрузка документов (PDF, JPEG, PNG, DOC, DOCX)
- Модерация документов: подтверждение или отклонение
- Асинхронные email-уведомления через Celery
- Мягкое удаление и восстановление аккаунта
- Документация API (Swagger / ReDoc)

## Роли и права

| Роль | Что может |
|------|-----------|
| **Пользователь** | Создавать, редактировать, удалять свои документы |
| **Модератор документов** | Подтверждать/отклонять любые документы |

## Установка и запуск

### Требования

- Python 3.13+
- Poetry
- PostgreSQL
- Redis

### Установка

#### 1. Клонируйте репозиторий:

- Ссылка на репозиторий: https://github.com/VikaDavlyatshina/Doc_Processing_Service

```bash
git clone https://github.com/VikaDavlyatshina/Doc_Processing_Service Doc_Processing_Service
```

#### 2. Перейдите в папку проекта

```bash
cd Doc_Processing_Service
```

#### 3. Установите зависимости

```bash
poetry install
```

#### 4. Настройте переменные окружения

 Отредактируйте .env: укажите параметры БД, почты, Redis

```bash
cp .env.template .env
```
> **Важно для Docker:** В `.env` для Docker укажите `DB_HOST=postgres` и `REDIS_HOST=redis` 
> (имена сервисов из `docker-compose.yml`), а не `localhost`

#### 5. Примените миграции и создайте группы

```bash
python manage.py migrate
python manage.py setup_moderator_group
python manage.py setup_user_manager_group
```
### Запуск

- **Запустите сервер**:

```bash
python manage.py runserver
```

- **Запустите Celery Worker (в отдельном терминале)**:

```bash
celery -A config worker -l info -P eventlet
```

- **Запустите Celery Beat (в отдельном терминале)**:

```bash
celery -A config beat -l info
```

## Запуск через Docker

1. Убедитесь, что Docker Desktop запущен

2. Создайте файл с настройками:
```bash
cp .env.template .env
```
3. Запустите все сервисы:

```bash
docker compose up -d --build
```
4. Откройте сайт: http://localhost:8080

## API Эндпоинты

### Пользователи

| Метод | Эндпоинт | Доступ | Описание |
|-------|---------|--------|----------|
| POST | `/api/users/register/` | Все | Регистрация |
| POST | `/api/users/token/` | Все | Получение JWT токена |
| POST | `/api/users/token/refresh/` | Все | Обновление токена |
| GET | `/api/users/profile/` | Авторизованные | Просмотр профиля |
| PATCH | `/api/users/profile/` | Авторизованные | Редактирование профиля |
| DELETE | `/api/users/profile/delete/` | Авторизованные | Мягкое удаление аккаунта |
| POST | `/api/users/profile/restore/{user_id}/` | Модератор пользователей | Восстановление аккаунта |

### Документы

| Метод | Эндпоинт | Доступ | Описание |
|-------|----------|--------|----------|
| POST | `/api/documents/` | Авторизованные | Создать документ |
| GET | `/api/documents/` | Авторизованные | Список документов |
| GET | `/api/documents/{id}/` | Авторизованные | Просмотр документа |
| DELETE | `/api/documents/{id}/` | Владелец | Удалить документ |
| POST | `/api/documents/{id}/submit/` | Владелец | Отправить на проверку |
| POST | `/api/documents/{id}/update-file/` | Владелец | Заменить файл |
| POST | `/api/documents/{id}/approve/` | Модератор документов | Подтвердить |
| POST | `/api/documents/{id}/reject/` | Модератор документов | Отклонить (с комментарием) |

### Уведомления (Celery)

| Событие | Получатель | Тема письма |
|---------|------------|-------------|
| Новый документ | Администратор | «Новый документ на проверку» |
| Документ подтверждён | Пользователь | «Ваш документ подтверждён» |
| Документ отклонён | Пользователь | «Ваш документ отклонён» |
